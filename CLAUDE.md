# Правила для Claude Code

Повний план: `docs/PLAN.md`. Стек і дизайн: `.cursorrules` (дизайн Mini App не змінюємо без явного запиту).

## Процес

- Перед кожним комітом і пушем показати зміни й дочекатися підтвердження.
- Одна фаза за раз: не починати наступну, поки не виконано критерій готовності поточної.
- Відповіді українською; код, коментарі й повідомлення комітів англійською. Тексти інтерфейсу — лише українською.

## Код

- Гроші тільки в центах (цілі числа), без float. Базова валюта — EUR.
- Кожна нова таблиця з даними має `space_id`, перевірку членства в API і тест на ізоляцію.
- Кожна таблиця має `created_at`, `updated_at`, `deleted_at` (м'яке видалення).
- Дати в UTC у базі; часовий пояс користувача — у профілі (за замовчуванням `Europe/Vienna`).
- Логіка без UI (парсер quick add, спліт, фонди) — чисті функції з тестами (`backend/tests`).
- Схема змінюється лише через Alembic-міграції.
- Жодних секретів у коді; нові змінні середовища описуються в `.env.example`.

## Команди

- Бекенд тести: `cd backend && uv run pytest`
- Фронт перевірка типів: `cd webapp && npm run typecheck`
